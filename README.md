\# Car Locating Assistance Program (CLAP)



This program helps users identify an appropriate luxury vehicle based on:

\- Preferred brand

\- Number of passengers

\- Off-road capability requirements



\## Features

\- Loads brand and model data from external GitHub-hosted text files

\- Uses user input to determine body style and recommend models

\- Supports restarting the program if inputs are incorrect



\## Technologies Used

\- Python

\- Git \& GitHub

\- Microsoft 365 Copilot
